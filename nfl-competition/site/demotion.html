Demotion gate

Ten triggers that send a live strategy back to paper, each with its metric, threshold, window and current reading.

The ladder runs one way

Promotion: Paper -> Provisional -> Live. Demotion: Live -> Paper. Not to Provisional: a demoted strategy re-enters at the bottom and passes G03, G04, G05 and G08 again on new data.

A strategy that was trusted and then stopped is more dangerous than one never trusted, because it has already carried a stake.

Every trigger, with today's reading

No strategy has ever reached the live tier, so no demotion has fired. Every trigger is published with the value it would read today so the gate can be inspected before it is needed.

Read it as a caution as much as a demonstration: the last 50 selections look much stronger than the full 120 for four of the six strategies, which is exactly the pattern a rolling window can mistake for an improvement. D01 exists to catch the move in the other direction, and would fire on the same kind of swing.
