RF-12correctedmediumTwo statistical defects found in this session's own code and fixed before publicationThe Benjamini-Hochberg step-up was computed from the smallest p-value forwards, which drags every later value down to the smallest one and reported an adjusted p of 0 for a raw p of 1. Separately, the t-test for a Pearson correlation returned values greater than 1.Both were visible in the output rather than in the code: every adjusted p printed as 0.0000, and two p-values printed as 1.94 and 1.74. Fixed by running the step-up from the largest rank downwards and by using the identity P(|T| > t) = I_x(df/2, 1/2) with x = df/(df + t^2). Both are now checked against known values: the incomplete beta returns 0.5 at (1, 1, 0.5), the normal CDF returns 0.975 at 1.96, and a correlation of exactly zero returns p = 1.None. Recorded so the fix is not mistaken for a silent edit.CP-NFL-RESULTS-W1-9
