Three rules bind this table

  • Every value is computed from numbers an official page printed.
  • Every row states its n. A row that cannot state one carries no value.
  • Club-level correlation is a different quantity from leg-level dependence and is labelled as such.

Caveats carried on the rows themselves

  • C05: Both series are built from the same club's same games, so the pair is not two independent measurements. Published as a description of the season, not as evidence.
  • C06: Pythagorean expectation is computed from the same points-for and points-against that decide the games, so a high correlation is a validity check on the formula, not a discovery.

A correlation between two clubs' season scoring rates says nothing about whether two legs inside one game move together. The level column exists so the two are never confused.
