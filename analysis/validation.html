05 / VALIDATION GATES

Eight gates. Three outcomes. "Unknown" is never "pass".

A strategy reaches the leaderboard only if every gate passes. Gates that cannot be evaluated return not evaluable, which makes the strategy unproven — not approved, and not rejected either.

WHY THIS ORDER

The gates run cheapest-first, and the cheap ones catch the most

G0 provenance catches the most common failure in this whole field: a number with no source, or a number that quietly changed definition between the input and the claim. One missing URL fails the gate.

G1 pre-registration is hashed, so a later edit to the thresholds changes the hash and invalidates the run. Without it, "we would have bet that anyway" is unfalsifiable.

G4 luck requires three separate tests to agree — an exact binomial test, the probabilistic Sharpe ratio, and the deflated Sharpe ratio. They fail in different ways, which is the point: a fat-tailed streak can pass one and fail another.

G6 correlation fails a parlay outright if its legs were assumed independent without a measurement. That single rule kills most plausible-looking parlay "systems".

G7 robustness deletes the best 5% of results and re-checks. A strategy whose entire edge comes from three lucky weeks fails here, which is the arithmetic version of "that was one good month".
