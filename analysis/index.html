NBA / ANALYSIS ENGINE

Originated lines, measured dependence, and a leaderboard that refuses to rank luck.

A reproducible engine that reads official NBA.com team data, originates spread / total / win-probability lines, measures real same-game dependence, and runs statistical gates before anything is allowed onto a leaderboard.

!
What this is not. There are no sportsbook prices here, because no official NBA source publishes them. Every line on this site is a model output computed from NBA.com ratings — not a market price, not a pick, not a result. No strategy has a settled, priced bet record, so no strategy is ranked. 05 / GATES

What must a strategy pass? ↗

Eight gates from provenance to robustness. Three-state outcomes, so "unknown" can never read as "pass".

 06 / COMPETITION

How is luck removed? ↗

Lower confidence bounds, deflated Sharpe, and the arithmetic of how many no-skill entries look good.
