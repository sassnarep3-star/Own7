THE TESTS THAT MATTER MOST

Closed-form anchors

Bivariate normal CDF

The parlay joint probability depends entirely on Φ₂. If that is wrong, every parlay number is wrong. The test pins it against the exact identity:

P(X < 0, Y < 0) = 1/4 + arcsin(ρ) / (2π) for standard bivariate normal checked at ρ ∈ {−0.9, −0.5, −0.2, 0, 0.2, 0.5, 0.9}, tolerance 1e-6

It also asserts Φ₂ reduces exactly to Φ(h)·Φ(k) at ρ = 0, and that the joint upper-tail probability is monotone in ρ.

Shrinkage limits

Zero games must return the league mean exactly; a large number of games must return the observed rating. Both are asserted, so an inverted weight formula cannot survive.

Vig arithmetic

De-vigging two −110 prices must yield a 4.77% hold and fair probabilities of exactly 0.5 each. The test asserts this rather than eyeballing it.

Determinism

One test re-runs the entire analysis as a subprocess and fails if any output byte changed. A result that moves between runs is not evidence.

Honest anchors that constrain the claims

  • 52.38% is break-even at −110, so a 55% record over 1,000 bets lands at p ≈ 0.052 — barely at the line. The test asserts this band rather than pretending such a record is decisive.
  • A zero-mean return series must not look significant in the block bootstrap.
  • "No bets" must produce the verdict unproven, never passed.
