What this site is

Own7 is a research dashboard for originating NBA lines. It collects official NBA.com statistics (team season stats, player per-game stats, standings), defines signal strategies for single bets, parlays, and player-prop combinations, and subjects every strategy to validation gates before it can appear on a leaderboard. The goal: selectively skill-based strategies with luck removed as far as the data allows.

  • Verified data only. Every table row carries a source link to an official NBA.com page. Values not confirmable from an official source are left blank and flagged as unverified.

  • No betting lines published by NBA.com. Market lines (spread, total, moneyline, player props) are intentionally blank; they must be captured from a sportsbook at bet time.
  • Leaderboard framework. Strategies report edge, correlation method, and sample size. Nothing is leaderboard-eligible until all gates pass.

Source discipline

  • Official source: NBA.com (stats pages, standings, schedule, team directory).
  • stats.nba.com JSON API is not reachable from this environment; correlation numeric values are blank and unverified.
  • No value is ever inferred. Blank + flagged = honest, reviewable, correctable.
