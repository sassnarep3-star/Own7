JOIN

Report designation against what actually happened

Each row of the weekly injury report is joined to the official Game Book Not Active list for the same club and game. The join key is club, surname and first initial: New England's report carries both A.J. Brown and Ben Brown, and the Game Book inactivates B.Brown, so a surname-only match would name the wrong man. Generational suffixes are stripped for the same reason - the report prints Carlton Davis III where the Game Book prints C.Davis.

'Not listed' is not 'available'

A majority of official inactives appear nowhere on the weekly injury report. The reasons are legion - injured reserve, the emergency third quarterback, a practice-squad activation, a club decision - and none of them is printed on the report page. Treating an absent row as a healthy player is wrong more often than it is right.
