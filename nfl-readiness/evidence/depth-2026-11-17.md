# Club depth charts as printed — 2026, read 2026-11-17

Six club pages were read this session. Each row below is copied from the club's own published depth-chart
page. The rules this desk applies to the transcription are stated once and then used everywhere:

1. **A slot is a group, not a starter.** A row with two or more rank-1 players (e.g. two receivers in the
   same cell) is transcribed with both names in column 1. Column 1 is *not* labelled "the starter".
2. **An empty cell stays empty.** Where a club leaves a column blank, the cell is blank here. A blank is
   not a zero and not a missing rank.
3. **Jersey numbers are kept verbatim** where the club publishes them (Green Bay) and are shown as printed.
   The parser strips the number only to match the name, and the raw string is retained beside it.
4. **A published date is recorded only where the page publishes one.** Green Bay prints
   `Unofficial, Nov. 10, 2026`; the others in this set print no date, so the date cell is blank.
5. **A club-stated caveat is recorded verbatim.** Detroit and Green Bay both call the chart unofficial.
