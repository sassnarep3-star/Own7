Does adding verified availability information change the model, and by how much?

Identical model, identical games, identical holdout. Only the personnel feature changes. This is the alternative to subtracting a fixed number of points for a missing starter, which no test in this repository supports.

The with-personnel arm is empty by construction, not by omission: no absence in the corpus is confirmed, so there is nothing to add. An empty arm is a finding, and it is why no fixed points penalty appears anywhere in the pipeline.

What would fill the empty arm

One season of official inactive lists joined to the corpus, so each game carries the set of confirmed absent starters. That is 136 inactive lists, of which 0 are captured.

Why not a fixed penalty

  • A fixed penalty encodes a belief about a player's value that has not been measured.
  • The measurement needs (a) a confirmed absence and (b) the same model run twice. (a) is missing.
  • Publishing the penalty anyway would make the model look informed while resting on an unmeasured assumption.
