Generic pricing identities

For decimal odds d > 1, implied probability is 1/d. No-push fair odds are 1/p; with push probability q, fair odds are (1-q)/p, undefined when p=0. Per-unit expected net return is p_win*(d-1) - p_lose.

A proportional de-vig convention normalizes reciprocal odds over a complete mutually exclusive outcome set from the same operator, line, timestamp and settlement contract. It is a modeling convention, not true-probability identification.

A parlay uses the actual joint event probability and actual operator combined quote. Product-of-probabilities requires full independence; product-of-odds is not a universal same-game payout rule.
