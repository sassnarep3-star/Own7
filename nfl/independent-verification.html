Status: pass. Run python nfl/verify_independent.py to repeat it. Reproduction shows that a published number follows from the published inputs. It does not show that the inputs match the live official pages, which is a separate dated act.

What was recomputed, and how

nfl/verify_independent.py shares no code with the pipeline that produced these figures. It reimplements Pearson and Spearman correlation, the league standings identities and the NFL passer-rating formula from the committed CSV snapshots, so a mistake in one implementation cannot silently confirm itself.

A real disagreement inside the official table

Two published yards-per-attempt values cannot be reached by rounding from the same row's own yards and attempts. They were re-fetched on 2026-11-12 and the official page still prints them, so this is a publisher-side disagreement between columns, not a transcription error. It is recorded as irregularity NF12 on the Flagged for Review page.

How much this matters

The Yds/Att versus Rate coefficient is 0.829085 on the column as printed and 0.831578 if exact yards per attempt is used instead, a difference of about 0.0025. The published figure is internally consistent with the column it names, so it stands as a descriptive statistic, but the exposure is published rather than hidden. No conclusion in this project depends on that coefficient, because no strategy has cleared a single evaluation gate.
