NFL / RESEARCH WORKSPACE

Methodology

Clear model contracts, correct pricing mathematics and a reproducible pipeline — with explicit release boundaries.

Reproduce without manual entry

python -m nfl_lab run
python -m unittest discover -s tests -v
python nfl/build.py
python scripts/check_site.py

The build is offline and deterministic from committed, receipt-checked snapshots. The analysis manifest contains input/code hashes and a run hash. No accounts, API keys, price entry, real-money wagers or source-data scraping is required.

Boundaries

Season aggregates are retrospective. Cross-sectional correlations are descriptive, not predictive. Rushing, receiving and team-offense headers are positional. Schedule/roster not transcribed. Injury replacements/deficiencies blank. NFL-derived betting prices withheld under NFL Terms.
