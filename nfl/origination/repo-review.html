This is a review of repository consistency and source discipline. It is not a re-verification of the inherited NBA or rental claims.

Method

The existing generator enforces a strict contract: every HTML page must be registered with a hash, every table body row must carry registered source IDs plus a link, and every blank cell must be genuinely empty. The NFL pages are built to the same contract, so a violation fails the whole site check.

The NFL data files were checked by arithmetic where arithmetic exists: win percentage, net points, the league-wide points identity, and the count of clubs in the slate against the count in the standings.
