How to read this list

These are not rhetorical. Each one is a question that, if answered the wrong way, makes a downstream decision wrong. The status column has four values and they mean different things:

  • answered - closed this session against an official page, with the link.
  • answered but constraining - we know the answer, and the answer limits what you may conclude. Q04 and Q05 are both like this: we know the data shows no skill and we know how much data would be needed, and both facts constrain every later decision.
  • open - no official source settles it yet, and the closing action is named.
  • blocked - it needs a permission, not more work. Q13 and Q14.
