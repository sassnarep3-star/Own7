What was actually done on 2026-11-14

The repository was audited and replayed green before any change: 109 tests, 38 canonical pages, 5,193 sourced table rows, zero link errors. Then this session added a new desk in its own directory and touched nothing outside it except appended navigation and source-register lines.

Verification. All 32 club standings rows were re-read from the official publisher, with the publisher's own arithmetic re-derived row by row and the league identity checked. 30 rows are unchanged from the frozen 12 November snapshot. Two clubs moved, and their deltas alone implied a single result, WAS scored 24, NYG scored 21, which is exactly what one played game does.

The gap that was found. Four clubs had never had a depth chart captured: CHI, DEN, PHI, TB. They are the four Week 10 bye clubs, which is precisely why the gap stayed silent - a bye club has no injury rows, so a missing chart never surfaced as an unmatched row. All four are now captured, 231 printed slots, and the injury-to-chart match rises to 265 of 326.

The answer to the main question

You asked to remove luck from the equation and build strategies that are selectively skill based. The honest answer is a measured one, and it is not encouraging:

The Pythagorean residuals across all 32 clubs sum to a chi-square of 19.0254 on 32 degrees of freedom, giving p = 0.966189. The variance inflation is 0.5945. On this snapshot the clubs are less dispersed than independent coin flips would make them, which is the opposite of the hidden-skill story. A leaderboard built on eight or nine games would be ranking noise, and the desk can demonstrate that rather than assert it.

Luck is removed by sample size and nothing else. At a 60% true rate it takes 154 settled independent bets to distinguish a real edge from break-even at 80% power. At a more realistic 52.4% it takes 2,682. The repository contains zero.

The three decisions worth making now

  1. Settle the rights question (P02). It is the only thing that unblocks prices, parlays, props and rewards. Everything else on this site is downstream of it. If the answer is no, the honest response is to stop describing this as a betting project and run it as availability research.
  2. Read the 28 club Friday reports (P01). Cheapest large win available. It turns game status from 4 clubs into 28 and it cross-checks the league aggregate, which one club already contradicts in public.
  3. Start the forward shadow ledger (P03) this week. It costs one row per fixture and it is the only path to the 153 settled bets. Every week without it is a week the competition cannot start.

What is not worth doing now: refining a model against this snapshot. The residuals are at p = 0.966189; there is nothing there to refine yet, and more modelling on eight games would produce confidence that is not warranted.
