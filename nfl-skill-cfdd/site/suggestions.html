Review these, then choose

Each suggestion states the evidence behind it, what it unlocks, what it costs, what could go wrong, and a test that can actually be run to know whether it worked. That last column is the point: a proposal without a pass/fail test is an opinion.

The order to read them in, if you want the shortest path to a decision that matters:

  1. P02, settle the rights question. Every price, parlay, prop and reward in this project is blocked behind it. Nothing else unblocks as much.
  2. P01, read the 28 club Friday reports. It closes the largest single blind spot - 24 clubs with no game status.
  3. P03, start the forward shadow ledger. It is the only route to a skill claim and it costs almost nothing to start now.

The rest can wait, and P06 (a second season) cannot be hurried at all.
