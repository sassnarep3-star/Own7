What "depletion" means here, precisely

A club is depleted at a slot when the player its own chart prints as first string is ruled Out and the chart prints somebody behind him in that same slot. That is it. The desk names the player, the printed position, and the next name the club prints in that slot, and it stops there.

It does not say the backup is three points worse, because no data in this repository can measure that. Snap counts and a before/after performance series would be needed, and neither was retrieved. That gap is question Q12 and suggestion P04.

Only four clubs publish a game status at all, so most clubs show a zero index because nothing is provable, not because nobody is hurt. That is flag CF07 and it caps every conclusion on this page.

The 7 starters it can prove are out, and who is printed behind them

  • DET — Cade Mays (C) → next printed name Juice Scruggs; D.J. Reed (CB) → next printed name Rock Ya-Sin
  • IND — Jaylon Carlies (WLB) → next printed name Bryce Boettcher; Akeem Davis-Gaither (MLB) → next printed name CJ Allen; Jalen Travis (RT) → next printed name Luke Tenuta
  • NE — Ben Brown (LG) → next printed name Walter Rouse; Carlton Davis III (CB) → next printed name Channing Canada

One more starter is out with nobody printed behind him:

  • IND — Luke Rhodes (LS) has no further name printed in that slot.

A slot is matched on the club, the unit, the printed position and the slot number the club itself uses - because a club restarts slot numbering for every position, so there are several "slot 1" rows in one unit. Matching on position alone would have attached the wrong backup to the wrong starter; that defect was found and fixed while building this page.

One ambiguity is left and it is published rather than resolved. 24 of the 265 matched rows are players their own club prints in more than one slot, and 1 of them is a ruled-out starter. The join uses one printed slot per player - the most prominent one - and marks every affected row. For an ambiguous starter the next name comes from that chosen slot, so it could differ in another slot the club also lists him in. Flag CF13.

The index is a weighted count of printed slots, using the disclosed weights (rank 1/2/3/4 = 1.00/0.45/0.20/0.10; Out/Doubtful/Questionable = 1.00/0.75/0.40). It orders clubs against each other. It is not a point value, not a probability, and it never multiplies a price. A club showing 0 has no starter it can prove is out, usually because the club publishes no game status at all.
