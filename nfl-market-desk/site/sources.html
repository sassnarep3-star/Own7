The register, one publisher per id, enforced by the build.

One publisher per id

12 sources are registered for this desk. Each id maps to exactly one publisher host, which is enforced by the repository check: a source id whose url does not match its registered host fails the build. That is why the relayed market feed has its own ids and never shares one with an NFL.com page.
