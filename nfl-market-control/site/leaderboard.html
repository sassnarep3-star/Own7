Signal vs staking

Separate skill evidence from price, staking, ROI, CLV and rewards.

One provisional signal is not one qualified strategy.

The signal table reports forecast evidence only. Its graded-bet count excludes pushes; the record shows wins–losses–pushes and hit rate uses decisive bets. The staking table is a separate economics ledger; no odds, stake, ROI, CLV or reward is populated. A lucky staking run cannot change the signal status.

INTERPRETATION

What the board does not mean

  • A hit rate is not profit: prices, vig, settlement, timing and stake determine net return.
  • Signal selection must be fixed before the test. All 30 tested variants remain visible so a top row is not cherry-picked.
  • Only the existing result-analysis status is reused: one row is provisional, none qualified. This page introduces no new ranking or reward.
  • Parlay and player-prop combinations require joint outcome data; the correlation page publishes n for the measured spread/total pair and leaves missing prop values blank.
