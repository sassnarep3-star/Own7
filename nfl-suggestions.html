DECISION PROCEDURE

How to choose: one page, four columns

Read a row in this order

  1. What it closes — the named missing item. If a proposal closes no named gap, reject it.
  2. Priority index — decision value times confidence gain, divided by effort plus cost. It is a judgement, published so you can disagree with it.
  3. What it unlocks — the decision that becomes possible.
  4. Acceptance test — what must exist before it counts as done.

Read the scores as opinions

  • decision_value: 1 = tidy-up, 5 = nothing can be decided without it
  • effort: 1 = hours, 5 = a multi-week data programme
  • cost: 1 = free, 5 = licence or paid feed required
  • confidence_gain: 1 = no belief changes, 5 = a published blank becomes a defensible value
  • reversibility: 1 = hard to undo, 5 = trivially undone
  • priority_index: decision_value * confidence_gain / (effort + cost), rounded to 2dp

Scores are 1-5 judgements made by this session, published so they can be argued with. They are not measurements.

REVIEW, NOT IMPLEMENTATION

Review workflow and what an approval must contain

The states

  • Proposed
  • Under review
  • Approved
  • Rejected
  • Implemented

No proposal is implemented until a reviewer records Approved. The site is static and provides no approval control; the decision is recorded by editing this file and rebuilding, which leaves an auditable commit.

Required at approval

  • reviewer role
  • decision date
  • acceptance test accepted or amended
  • the question it closes

A rejected suggestion keeps its row and gains a reason. Nothing is deleted, so the same idea is not silently re-proposed.

HOW TO JUDGE A CHANGE

Acceptance tests for any proposal at all

  • A proposed change must name the question it closes and the file that will hold the new evidence.
  • No cell may move from blank to a value without an official URL and a check date.
  • A strategy may only leave the blocked state when every applicable gate cites an artifact URL.
  • The site must rebuild byte-identically after the change, with no broken links.
  • An option that adds a number but no verification must be rejected.
