# Repository review — checked line by line

Scope: the repository that hosts this desk, at its state on 12 November 2026. Eighteen claims were
checked by running the thing the claim describes, not by reading the prose that makes the claim.
Result: **10 Verified, 8 Irregular**. Every measurement is stated in the state it was taken
in, because this session adds an NFL sub-site and could otherwise make earlier numbers look wrong.

Machine copy: [`nfl-desk/data/repo-review.json`](../../nfl-desk/data/repo-review.json).
Rendered copy: <https://sassnarep3-star.github.io/Own7/nfl-desk/evidence.html#repo-review>.

An **Irregular** row is not an accusation of bad faith. It means the repository asserts something
that a re-run does not reproduce, or asserts something no file supports. Each irregular row states
what a re-run actually produced, and the stale-artefact rows are also raised as proposals SG-10 and SG-12 on
`nfl-desk/suggestions.html`.

## The irregular rows, in one place

Each is stated with the measurement that produced it. None is a stylistic objection; every one
is a claim the repository makes about itself that a re-run did not confirm.

1. **README summary metrics** (`R03`) — The README's stated inventory matches the repository. Discrepancy. The README still quotes '36 HTML paths', '541 source-linked table rows', '75 Python tests' and '18 open flags' from an earlier integration. Current state: 54 HTML files, 738 table rows, 81 tests, 22 open review flags in research/catalog.json. The '107 checked official snapshot rows' figure does still match (30 + 15 + 30 + 32 = 107).

The committed artefact records 15 canonical pages, 36 recursive pages and 541 table rows; the current run reports 25, 54 and 738. The stamp is hard-coded in the shared page template, so it is right for the NBA data and wrong for the rental data.
4. **Coordinated parallel sessions** (`R10`) — The coordination board reflects the current state of work rather than a historical one. Irregular. The board contains 18 rows marked 'in progress' and 3 marked 'unclaimed' from earlier sessions whose branches were merged days ago, plus at least five separate 2026-11-12 NFL claims in different scopes. ## What this review is and is not

It is a re-run of eighteen checkable claims. It is **not** a code review, a security review or a
licence opinion. No claim here was accepted on the basis of a commit message, a comment, or another
document in the repository.

Method note: every command used is a plain, offline command in the repository (`python -m unittest`,
`python scripts/check_site.py`, `python scripts/build_site.py`, `ls`, `git log`, `git status`,
`python -c`). Any reader can repeat them. Where a check needed network access, it is not in this
table — it is in the source ledger at [`docs/nfl-desk/sources.md`](sources.md).
