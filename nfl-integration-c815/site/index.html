The one thing that changed today

The Week 10 slate is complete. Chargers 23, Ravens 20 was final on the official Week 10 page, and the official standings now credit both clubs for it. The canonical results feed in this repository still holds 149 games, because it was built before that game finished. The official standings arithmetic implies 150. The gap is exactly one game, and this desk proves it three independent ways — see Week 10 completion.

Nothing was patched in another session's file. The feed is flagged, the proof is published, and the fix is a one-line change to a file this session does not own.

How to read this desk

  • Every number is arithmetic. Each count on every page is computed from the rows above it, or extracted literally from an official capture. A build that cannot reconcile aborts instead of publishing.
  • Two columns, always. Where a value comes from another desk, this desk shows that desk's published claim next to its own independent check. It never silently upgrades a status.
  • Blanks are real. A cell with no official value is empty and carries a reason. No frequency, price or prior is estimated anywhere.
