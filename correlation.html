Estimation protocol · project design

Join by official game ID and player ID; exclude incomplete pairs and report exclusions. Report season, cutoff, N, coefficient and game-date block-bootstrap 95% interval. Constant series have undefined correlation; leave blank. Pearson measures linear association, not causation or independence. Spearman is a sensitivity check. Never substitute a logistic regression coefficient for a correlation.

For two no-push binary legs, the identity P(A∩B) = pA pB + ρ √[pA(1−pA)pB(1−pB)] only works when ρ refers to those exact binary events. It does not allow plugging in raw player-stat correlation. Estimated joint probabilities must satisfy max(0,pA+pB−1) ≤ P(A∩B) ≤ min(pA,pB). For three or more legs, model and validate the full joint distribution.
